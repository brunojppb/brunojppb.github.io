# Blog feature map

One file per feature a reader uses. Each says how to reach it, how to drive it, and what proves it.

- [search.md](search.md): the Ctrl+K palette. Driven by `scripts/drive-palette.mjs`.
- [listing.md](listing.md): `/posts/` year groups and tag counts.
- [post.md](post.md): a post page, its outline rail, and its code blocks.
- [layout.md](layout.md): no sideways scroll, clean console, at every width.
